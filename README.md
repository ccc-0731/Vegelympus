# 奥林匹菜市场 · Vegelympus

菜市场众神居住的水墨神山，也是一个献给高中同学圈子“菜市场”的互动纪念网站。

## 目前可以玩什么

- 在神山地图拜访六座神庙
- 使用菜种在十块菜地播种，30 秒后收获
- 带成熟蔬菜去山腰市场和众神换新种子
- 在神坛留言、随机获得神秘种子、抽取菜签
- 查看菜之图鉴和众神显灵记录
- 用浏览器本地存储自动保存全部进度

## 本地预览

这是零依赖静态站点。直接打开 `index.html`，或在仓库目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 发布到 GitHub Pages

在 GitHub 仓库的 **Settings → Pages** 中，将 Source 设为 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 目录并保存即可。

## 数据与多人功能

当前版本无需登录，昵称、菜园、图鉴和留言都只保存在当前浏览器。若之后要让不同用户互相看到神庙祈福，可接入 Supabase Auth + Database + Realtime；在配置云端密钥前，本项目不会上传任何数据。
